# TogetherPlan

## Descrierea proiectului
TogetherPlan este o aplicație web destinată organizării activităților cotidiene în grup. Aplicația permite utilizatorilor să gestioneze sarcini, liste de cumpărături, evenimente și cheltuieli comune într-un singur loc.

## Problema abordată
Organizarea activităților între colegi, studenți sau membrii unei familii poate fi dificilă atunci când informațiile sunt împărțite între mesaje, agende și aplicații diferite. Pot apărea sarcini uitate, neînțelegeri privind responsabilitățile și dificultăți în urmărirea cheltuielilor.

## Scop și obiective
Scopul proiectului este dezvoltarea unei aplicații web care simplifică organizarea și colaborarea în grup.

Obiective:
- Centralizarea sarcinilor și activităților într-o singură aplicație.
- Distribuirea responsabilităților între membrii unui grup.
- Organizarea listelor comune de cumpărături.
- Vizualizarea termenelor-limită într-un calendar.
- Urmărirea cheltuielilor comune.

## Utilizatori vizați
- Studenți care locuiesc sau lucrează împreună.
- Colegi de apartament.
- Familii și grupuri mici.

## Funcționalități propuse
1. Înregistrare și autentificare utilizatori.
2. Creare, modificare, atribuire și finalizare sarcini.
3. Creare și gestionare liste colaborative de cumpărături.
4. Vizualizarea activităților și termenelor-limită într-un calendar.
5. Înregistrarea și consultarea cheltuielilor comune.

Prioritate principală: autentificare, sarcini și liste colaborative. Calendarul și bugetul sunt funcționalități secundare.

## Tehnologii propuse
- HTML – structura paginilor web.
- CSS – aspectul vizual și organizarea interfeței.
- JavaScript – interactivitatea paginilor.
- Node.js și Express – serverul și API-ul aplicației (propunere preliminară).
- SQLite – stocarea datelor (propunere preliminară).
- Git și GitHub – versionarea și colaborarea.
